# Mapa Conceitual BSI IFMG - Campus Ouro Branco

Mapa conceitual digital e interativo desenvolvido para apresentar as relações entre as disciplinas do curso de **Bacharelado em Sistemas de Informação do IFMG - Campus Ouro Branco** e diferentes possibilidades de atuação profissional na área de Tecnologia da Informação.

O projeto busca permitir que estudantes interessados no curso compreendam de forma visual como a matriz curricular, os eixos de formação e as disciplinas se relacionam com diferentes trilhas de carreira.

## Sobre o projeto

A aplicação organiza as informações do curso a partir de três elementos principais:

- **Trilhas de Carreira:** permite selecionar diferentes possibilidades de atuação profissional relacionadas à formação em Sistemas de Informação;
- **Conexões Interativas:** apresenta as disciplinas relacionadas à carreira selecionada e suas relações com os respectivos eixos de formação;
- **Matriz Curricular:** exibe as disciplinas do curso organizadas por período, destacando aquelas relacionadas à carreira selecionada.

Ao selecionar uma carreira, as demais visualizações são atualizadas automaticamente, permitindo explorar de maneira simples quais conhecimentos e disciplinas contribuem para aquela trajetória profissional.

Também é possível selecionar disciplinas individualmente para visualizar informações acadêmicas e suas relações com diferentes carreiras.

## Funcionalidades

- Seleção de trilhas de carreira;
- Visualização das disciplinas relacionadas a cada carreira;
- Conexões interativas entre carreiras, disciplinas e áreas de formação;
- Matriz curricular organizada por período;
- Destaque das disciplinas associadas à carreira selecionada;
- Visualização de detalhes das carreiras;
- Visualização de informações individuais das disciplinas;
- Interface responsiva para diferentes tamanhos de tela;
- Navegação sem necessidade de recarregar a página.

## Tecnologias

O projeto foi desenvolvido utilizando tecnologias nativas da Web:

- HTML5
- CSS3
- JavaScript

Não foram utilizados frameworks ou bibliotecas de interface.

## Fonte dos dados

As informações acadêmicas utilizadas no projeto foram baseadas no **Projeto Pedagógico do Curso (PPC) de Bacharelado em Sistemas de Informação do IFMG - Campus Ouro Branco**.

As relações entre disciplinas, áreas de conhecimento e possibilidades de carreira foram organizadas com o objetivo de representar visualmente diferentes caminhos profissionais relacionados à formação oferecida pelo curso.

## Estrutura do projeto

A aplicação é executada inteiramente no navegador e não necessita de backend ou banco de dados.

De forma geral, o projeto é composto por arquivos responsáveis por:

- estruturar o conteúdo da página;
- estilizar a interface;
- armazenar os dados das disciplinas e carreiras;
- controlar a lógica de interação;
- renderizar e atualizar as visualizações da aplicação.

## Executando localmente

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/mapa-conceitual-SAD.git
```

Acesse a pasta do projeto:

```bash
cd mapa-conceitual-SAD
```

Em seguida, abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar um servidor local, como a extensão **Live Server** do Visual Studio Code.
